Production configuration

Public contact and storefront settings are stored in JS/site-config.js. Private values are stored only as Railway environment variables.

  • Storefront: https://nafees-frontend-production.up.railway.app
  • API: https://nafees-backend-production.up.railway.app/api
  • Currency: EGP
  • Payment: Cash on Delivery only
  • Admin data: protected API and MongoDB

Never place database URLs, JWT secrets, or administrator passwords in frontend files.
